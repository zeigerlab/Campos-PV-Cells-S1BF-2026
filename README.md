# Campos PV Cells S1BF 2026

The script "Campos_PV_Cells_S1BF_Analysis_Script.m" was written in MATLAB 2020b. Associated data tables can be downloaded from https://drive.google.com/file/d/1sLu-iqP9UBKcwAWA39TE9xUHFwwxYTa5/view?usp=sharing. 

Once you download and unzip the data tables, set the current directory to the folder containing the data tables. Then you can step through the sections of the script to reproduce figures from the manuscript.
